📚 Informações Importantes sobre JWT

  • Header: Algoritmo e tipo do token (ex: { "alg": "HS256", "typ": "JWT" })
  • Payload: Dados do usuário e metadados (claims)
  • Signature: Assinatura digital para garantir integridade
  • NUNCA armazene dados sensíveis no payload (é Base64, não criptografado)
  • SEMPRE valide o token no servidor antes de autorizar acesso
